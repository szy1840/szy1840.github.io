How Does Claude Motion Make Animations, and What Does It Have to Do with Remotion?

2026-11-25 · AIAnimationRemotionVideo

On this page

On October 8, Anthropic released Claude Motion: you describe what you want, and Claude makes a short animated explainer you can export as an MP4. I wanted to know whether it runs on Remotion. The answer: Anthropic hasn’t published how it works, and I found no evidence that it uses Remotion.

What is public

Runway’s launch announcement1 confirms that the picture is built from the text, charts, shapes and images in your material; that “Claude writes the code that animates your content”, so the animation is code Claude writes; and that you can revise it in conversation or in an editor and export an MP4. Third-party reports also relay Anthropic as saying Motion does not use a video generation model (I haven’t checked this on Anthropic’s own pages). Nothing is said about the framework or how it renders.

How code animation becomes video

The core rule of these tools: the picture depends only on the time t.

  1. Write the picture as render(t). The same t always draws the same frame, with no dependence on the real clock or random numbers.
  2. For preview, requestAnimationFrame calls render(t) with the current time, so it looks like playback.
  3. For export, a headless browser sets t frame by frame, takes screenshots, and hands them to FFmpeg. It isn’t screen recording, so every frame is exact.

Remotion works the same way

Remotion is an open-source framework for writing videos in React. useCurrentFrame() returns the current frame number and the component computes the picture from it, which is a React version of render(t). To render, it also captures frames in a headless browser and hands them to FFmpeg2. Individuals and companies of up to 3 people can use it for free; larger companies need a commercial license3.

Does Motion use Remotion?

I don’t know; both routes work. My guess is that it’s built in-house: Motion is previewed and edited inside Claude, Artifacts are already web pages, so writing a page with a render(t) is the simplest path, while Remotion adds a React project and a bundling step. But that is only a guess.

As an aside, there’s a community project on GitHub with the same name, whaleyxbt/claude-motion4. It has nothing to do with Anthropic, but it implements both routes: one with Remotion, and one, sims/, where each piece is a single HTML file with a render(t) that headless Chromium captures frame by frame into ffmpeg. It works as a reference implementation.

10 月 8 日，Anthropic 发布了 Claude Motion：描述想要的内容，Claude 做出一段短的动画讲解，可以导出成 MP4。我想知道它底层是不是 Remotion。结论是：Anthropic 没有公开实现，我也没找到它用了 Remotion 的证据。

公开的信息

Runway 的发布公告1能确认：画面由你材料里的文字、图表、形状和图片组成；“Claude writes the code that animates your content”，也就是说动画是 Claude 写的代码；可以对话修改或在编辑器里调整，导出 MP4。第三方报道还转述 Anthropic 的说法，Motion 没有用视频生成模型（这一点我没在官方页面上核实）。底层框架和渲染方式都没有提。

代码动画怎么变成视频

这类工具的核心约定是：画面只由时间 t 决定。

  1. 把画面写成 render(t)，同一个 t 永远画出同一帧，不依赖真实时钟或随机数。
  2. 预览时用 requestAnimationFrame 拿当前时间调用 render(t)，看起来就是在播放。
  3. 导出时用无头浏览器逐帧设置 t、截图，交给 FFmpeg 编码。这不是录屏，所以每一帧都是准的。

Remotion 也是这么做的

Remotion 是用 React 写视频的开源框架。useCurrentFrame() 返回当前帧号，组件据此算出画面，相当于 React 版的 render(t)；渲染时同样是无头浏览器逐帧截图，再交给 FFmpeg2。个人和 3 人以内的公司可以免费用，更大的公司需要商业授权3。

Motion 用的是 Remotion 吗

不知道，两条路都走得通。我猜是自研的：Motion 在 Claude 里预览和编辑，Artifact 本来就是网页，直接写一个带 render(t) 的页面最省事；Remotion 还要 React 工程和打包，链路更长。但这只是推测。

顺带一提，GitHub 上有个同名的社区项目 whaleyxbt/claude-motion4，和 Anthropic 无关，两条路都实现了：一条用 Remotion，另一条 sims/ 是单个 HTML 文件加 render(t)，由无头 Chromium 逐帧截图交给 ffmpeg。可以当参考实现。
